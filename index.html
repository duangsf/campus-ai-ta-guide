⚙️ 系统设置

云端大模型模式需要 API Key（通过 node server/server.js 启动以规避跨域）； 无 Key 时会自动降级为本机知识库模式，完全离线可用，路演现场零风险。

Key 仅保存在本机浏览器 localStorage，不会写入代码仓库。

两种模式共用同一套检索引擎与置信度闸门，答案口径一致，差别在链路长度与可见性。极速模式不依赖模型的工具决策，因此知识注入更可控（模型偶尔会跳过检索凭记忆作答）。上游延迟本身波动较大，现场两种模式都可以试一下再定。
